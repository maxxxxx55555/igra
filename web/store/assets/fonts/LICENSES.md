# Font provenance — release landing page

The three fonts in this directory are byte-identical copies of the fonts the
game already ships in `assets/fonts/`, so the release page renders with the
same typography offline, without a third-party CDN request. They are loaded by
`@font-face` in `assets/css/styles.css`.

| File | Typeface | Licence | Full record |
|---|---|---|---|
| `BebasNeue-Regular.ttf` | Bebas Neue (Ryoichi Tsunekawa / Dharma Type) | SIL OFL 1.1 | `assets/fonts/THIRD_PARTY_FONTS.md` |
| `RobotoCondensed-Full-VF.ttf` | Roboto Condensed variable (Roboto Project Authors) | SIL OFL 1.1 | `assets/fonts/RobotoCondensed-Full-VF.LICENSE.md`, `RobotoCondensed-Full-VF.SOURCE.md` |
| `ShareTechMono-Regular.ttf` | Share Tech Mono (Map-Type / Vitalii Maltsev) | SIL OFL 1.1 | `assets/fonts/THIRD_PARTY_FONTS.md` |

None of the files were modified. All three licences allow embedding in a
commercial product. No external font URL is used by this page.
