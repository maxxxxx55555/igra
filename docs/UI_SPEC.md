# UI_SPEC — The Last Streetlight (раскладка всех экранов по мудбордам)
Стиль/токены/шрифты — см. docs/ART_UI_STYLE.md (не дублировать). Фото-ассеты внутри плашек = плейсхолдеры ColorRect/процедурные силуэты со слотом texture под .png позже. Все экраны через PanelCard (задача 2). screen_router enum ниже. Микровзаимодействия глобально: tween появления 0.18s, hover/pressed на кнопках, амбиент-фон у меню/загрузки = размытый 3D-кадр (SubViewport или ColorRect-градиент #0c1016->#141a26 если дорого).

## ШАБЛОНЫ раскладки (все плашки одного языка):
T_LIST_PREVIEW = заголовок сверху + вкладки-табы под ним + слева список/колонка + справа превью-панель + низ-кнопки.
T_GRID_CARDS = заголовок + вкладки + сетка карточек (иконка-плейсхолдер brass-dim + название bone-text + цена/значение + кнопка) + шапка-счётчик (монеты/вес).
T_TABLE = заголовок + вкладки + таблица «параметр слева — значение/слайдер/выпадающий справа» + низ «ПРИМЕНИТЬ / ПО УМОЛЧАНИЮ / НАЗАД».
T_FULLSCREEN_PREVIEW = превью на весь фон + оверлей-плашки по углам + нижняя строка (диалог/цель/совет) + кнопка закрыть/пропустить.
