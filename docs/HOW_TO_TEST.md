# Как проверить игру

Документ для владельца проекта: как убедиться, что игра работает, и что
именно смотреть глазами. Ничего из этого не требует знания кода.

---

## 1. Быстрая проверка без движка (30 секунд)

```bash
./tools/check.sh --static
```

Проверяет то, что чаще всего ломается незаметно: битые ссылки на файлы,
несуществующие вызовы к автозагрузкам, дыры в переводах, целостность
цепочки «загрузка → меню → игра → районы → враги».

Ожидаемый результат — все строки `OK` и `Всё зелёное`. Код возврата 0.

## 2. Полная проверка с движком

Нужен [Godot 4.x](https://godotengine.org/download) (обычная версия, не .NET).

```bash
./tools/check.sh
# или, если godot не в PATH:
GODOT="/путь/к/Godot_v4.x_linux.x86_64" ./tools/check.sh
```

Дополнительно прогоняет шесть гейтов прямо в движке:

| Гейт | Что ловит |
|------|-----------|
| компиляция всех скриптов | синтаксические ошибки в любом `.gd` |
| арность сигналов | несовпадение числа аргументов у `emit`/`connect` |
| API автозагрузок | вызовы несуществующих методов |
| локализация | пропущенные ключи, расхождение языков |
| ассеты | отсутствующие иконки, звуки, музыка |
| прогон 3D-сцены | сцена реально поднимается без ошибок |

Любой красный гейт печатает последние 15 строк лога — там видно причину.

## 3. Запуск игры

```bash
godot --path .            # или откройте папку проекта в Godot и нажмите F5
```

## 4. Что проверить руками

Порядок примерно соответствует пути игрока. Если пункт не выполняется —
это баг, который стоит мне прислать.

### Меню и настройки
- [ ] Экран загрузки сменяется главным меню сам
- [ ] «Продолжить» появляется только когда есть сохранение
- [ ] Настройки → смена языка меняет текст **сразу**, включая магазин,
      бестиарий и достижения (13 языков)
- [ ] Настройки → отдельные ползунки «Музыка» и «Эффекты» слышимо
      меняют громкость независимо друг от друга
- [ ] Esc в меню открывает подтверждение выхода, «Нет» возвращает назад

### Игровой мир
- [ ] Игрок ходит на WASD, мышь вращает камеру, Shift — бег, Ctrl — тишина
- [ ] `F` включает фонарь, батарея тратится, в темноте видно разницу
- [ ] `1`–`6` используют предметы из быстрых слотов (это чинилось недавно)
- [ ] По району разбросаны светящиеся предметы, их можно поднять,
      счётчик в инвентаре растёт
- [ ] В каждом районе лежит документ; при подборе всплывает
      «НАЙДЕН ДОКУМЕНТ» и он появляется в журнале
- [ ] Враги отличаются по районам: в пригороде — тени и ползуны,
      на электростанции — тяжёлые разрушители
- [ ] В неосвещённом районе врагов заметно больше, чем в восстановленном

### Звук
- [ ] В меню играет одна музыка, в игре — другая
- [ ] При приближении врага музыка нарастает, в бою переключается
- [ ] Слышны шаги, они меняются по поверхности

### Прогресс и сохранения
- [ ] Квесты в журнале двигаются: убил врага — счётчик вырос
- [ ] За выполненный квест начисляются монеты
- [ ] Сохранение → выход в меню → загрузка возвращает район, позицию,
      инвентарь **и прогресс квестов**
- [ ] Достижения открываются и показываются на своём языке

### Экраны
- [ ] Открываются без ошибок: инвентарь, карта города, журнал заданий,
      бестиарий, магазин, верстак, достижения, статистика
- [ ] Ни один экран не «залипает»: закрытие возвращает управление игроку

## 5. Сборка под Android

```bash
# один раз: в Godot → Editor → Manage Export Templates → Download
godot --headless --path . --export-release "Android" build/game.apk
```

Перед сборкой в `Project → Export → Android` проверьте: `arm64-v8a`
включён, `Debug` выключен, указан keystore для релиза.

## 6. Если что-то упало

Запустите с выводом ошибок и пришлите последние строки:

```bash
godot --path . 2>&1 | tail -40
```

Самое полезное в логе — строки со словами `SCRIPT ERROR`, `Invalid call`
или `Cannot open file`.
