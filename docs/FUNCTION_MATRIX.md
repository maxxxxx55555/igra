# Function matrix (P1, order-pass v8)

Every player-reachable function/mechanic, enumerated from the project's own config rather than
by memory, so completeness can be proven instead of assumed.

## Methodology and completeness proof

- **Spine** (rows AL01-AL57, IN58-IN89): generated by `tools/qa_sim/gen_function_matrix.py`
  straight from `project.godot`'s `[autoload]` and `[input]` sections — one row per autoload,
  one row per input-map action. Re-run it after adding/removing an autoload or input action;
  its stderr line (`Total spine rows: N (A autoloads + B input actions)`) must match
  `grep -c "^AL\|^\w\+="` against the live `project.godot` sections, proving no row was dropped
  or invented by hand. **Current: 89 spine rows (57 autoloads + 32 input actions).**
- **Extra rows** (rows X01+): non-autoload systems the spine can't see on its own — UI screens
  reached only through `Routes`, gameplay mechanics living on scene-local scripts (stealth,
  boss), and the three standing bugs the order-pass directive explicitly names as matrix rows.
  Hand-curated from a targeted read of `scripts/enemies/`, `scripts/player/`, and this session's
  own G0/G1/P0 work — not exhaustive of every scene script in the project, but covers every
  category the directive names (save/NG+/achievement/security/economy/stealth/boss/
  district/audio/i18n) at least once.
- **Status legend**: `WORKS` (verified this pass, method stated) · `BUG` (verified broken,
  see linked doc for detail) · `CANNOT-TEST-HEADLESS` (needs a live window/audio device this
  environment's automated battery can't provide, see `docs/RUN_STATE.md`'s G0/P0 findings) ·
  `BY-DESIGN-LIMIT` (working as intended, limited by something outside the codebase) ·
  `UNTESTED` (not yet exercised this pass — the P2 sweep's job, not a claim of "broken").
