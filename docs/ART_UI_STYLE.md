# Арт-библия — The Last Streetlight

## Принцип температуры

Визуальный язык построен на контрасте **холодной тьмы** окружения и **тёплого света** источников (фонарик, костры, убежища). Цветовая температура — главный навигационный и атмосферный инструмент.

### Свет и тьма (permanent night)

Ночь — **всегда**, на всей карте, без исключений. Дня/солнца нет. Источники света, спасающие от темноты:
- **Фонарик игрока** (конус SpotLight3D, тёплый `#c9a24a`) — единственный источник в DARK-зонах.
- **Уличные фонари** (Streetlight3D, `#c9a24a`) — горят ТОЛЬКО в починенных зонах (LIT/FULL).

Освещение модулируется по стадии района (DistrictManager.stage / PowerGridManager.restore):

| Стадия | restore | Уличные фонари | Окружение |
|--------|---------|----------------|-----------|
| **DARK** | < 60 | Выключены (разбиты/не работают) | Почти pitch‑black: ambient ~0.03, луна ~0.12 — только силуэты стен вне конуса фонарика |
| **LIT** | 60–99 | Горят (энергия ~2.0, мерцание) | Умеренная ночь: ambient ~0.11, луна ~0.25 — детали читаются, но темно |
| **FULL** | 100 | Горят ярче (энергия ~3.5, стабильно) | Яркая ночь: ambient ~0.16, луна ~0.40 — район «спасён», визуальная награда |

Прогресс починки (рост restore) = зажглись фонари = район становится безопаснее и светлее. Контраст «тьма → зажглись фонари» — главная визуальная награда игрока.

### Запреты
- Чистый `#000000` и `#ffffff` — запрещены. Самый тёмный = `#0c1016`, самый светлый = `#d8d2c4`.
- Неоновые/кислотные цвета — запрещены.
- Любой цвет берется приглушённым, с низкой насыщенностью (saturation < 40% для фонов, < 60% для акцентов).

## Панели и окна

- Фон: `panel` (`#141b24`).
- Рамка: 1px `panel-edge` (`#2a3340`).
- Углы: срезанные (chamfer), не скруглённые.
- Подложка: текстура зерна (grain) с низкой непрозрачностью (~8-12%) + виньетка по краям.
- Тень панели: лёгкая dropshadow, смещение вправо-вниз, `#000` при opacity ~30%.

### Строгий запрет
- Glasmorphism (стекло, backdrop-blur, сатурация/blur фона) — запрещён.

## Иконки

- Линейные (outline), толщина линии 1.5-2px.
- Цвет: `brass` (`#c9a24a`) для активных, `brass-dim` (`#8a7338`) для неактивных.
- Без заливки, без градиентов.

## Панель фонарика

Сегментированные бары — 5-10 сегментов, каждый гаснет по мере разряда:
- Полный: `brass`
- Средний: `brass-dim`
- Пустой: `panel` + рамка `panel-edge`

## Инвентарь

- Сетка 4×N (4 колонки на мобилке).
- Ячейка: 64×64dp, фон `panel`, рамка 1px `panel-edge`.
- Выбранный предмет: рамка `brass`.
- Строка веса внизу: полоска-прогрессия от `stamina` (зелёный) → `brass` (жёлтый) → `ember` (красный) по мере заполнения.
- Текст: `steel-text`, цифры веса: `Share Tech Mono`.

## 3D-грейд (WorldEnvironment) — Mobile (Android)

Параметр | Значение
---------|---------
Tonemap | **AgX** (основной) — единственный, не менять
Ambient light | DARK ~0.03 / LIT ~0.11 / FULL ~0.16 (модуляция по стадии района; см. «Свет и тьма»)
Moon energy | DARK ~0.12 / LIT ~0.25 / FULL ~0.40
Moon shadow | **Включены** (shadow_enabled = true) — силуэтный rim в DARK, читаемые тени в LIT/FULL
Depth fog | **Включён** — холодный отлив (`#1a2133` — тон в тон с `fog_light_color` в коде), density 0.012–0.015
SSAO | **Выключен** — недоступен на Mobile
SSIL | Выключен (тяжёлый для мобилки)
Volumetric fog | **Выключен** — недоступен на Mobile; объём/атмосферу дают depth fog + частицы haze/steam/ash из StreetBuilder
Glow | Только для эмбиент-точек (костры), минимальный
Tone map exposure | По настройке сцены
Brightness | 1.0 (коррекция пост-процессингом не нужна)
Contrast | 1.0

### Цветокоррекция
- Тени: холодный отлив (blue-ish).
- Света: тёплый отлив (amber/orange).
- Look-up Table (LUT): кастомная, с приглушённым контрастом.

### Луч фонарика
- **SpotLight3D** с процедурным конусом-мешем (ShaderMaterial: `blend_add`, `unshaded`).
- Параметры: angle ~60°, attenuation 0.8-1.0, range 8-12 м.
- Цвет света: тёплый (`#d4a04a` → `#c9a24a`).
- Цвет тени: без тени (shadow = false) — экономия производительности.

### Гибридный рендерер (планируется)
Для десктопной версии — переключение на **Forward+**: тогда включаются Volumetric fog + SSAO half-res.
Пока весь таргет — Mobile; forward-фичи в коде отключены.

## Реализация в Godot 4.7

### Theme
- **Theme** — единый на проект, создаётся как ресурс `.tres`.
- StyleBox для Panel/PanelContainer: StyleBoxTexture с текстурой зерна/рамки + chamfer-углы (9-patch).
- Для Button: StyleBoxFlat с 1px рамкой, фон `panel`.
- Цвета шрифтов: `steel-text` / `bone-text` через Theme.

### Зерно и виньетка
- **ColorRect** на CanvasLayer (поверх всего UI), материал ShaderMaterial с шейдером зерна.
- Второй ColorRect для виньетки — radial gradient от прозрачного → `#0c1016` к краям.

### Луч фонарика
- SpotLight3D как дочерняя нода игрока.
- SpotLight3D.BakeMode = Disabled (realtime).

### Туман (depth fog)
- Туман = depth fog через `Environment.fog_enabled` + `fog_density` + `fog_light_color` (`#1a2133` — холодный ambient, тон в тон с кодом `world_env_setup.gd`/`fog_setup.gd`).
- Объём/атмосферу усиливают GPUParticles3D haze/steam/ash из StreetBuilder.
- FogVolume / FogMaterial НЕ используем — volumetric fog недоступен на Mobile (рендерер Mobile; см. таблицу 3D-грейда).
