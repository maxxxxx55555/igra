# Что нужно сделать перед первой игрой

Правки этой сессии проверены статически: `./tools/check.sh --static` — 12 гейтов,
66 проверок игрового цикла, 285 файлов через `gdparse`. Всё зелёное.

Но **игра ни разу не запускалась**: Godot в рабочем окружении недоступен
(зеркала бинарников закрыты). Поэтому всё, что видно только глазами —
раскладка, свет, анимации, положение объектов в мире — остаётся за вами.
Ниже ровно то, что нужно проверить, и почему именно это.

---

## Шаг 1. Сгенерировать `.import` и `.uid` (делается один раз)

В репозитории нет метаданных импорта: старый `.gitignore` содержал правила
`*.import` и `*.uid` из эпохи Godot 3. Правила убраны, но сами файлы умеет
создавать только редактор.

1. Откройте `project.godot` в **Godot 4.7 Stable**.
2. Дождитесь окончания импорта — прогресс-бар внизу справа.
   Импортируется **156 ассетов** (текстуры, шрифты, звуки), это займёт время.
3. Предупреждения вида `ext_resource, invalid UID ... using text path instead`
   при первом открытии — **ожидаемы**. Движок находит файл по обычному пути и
   заводит UID заново.
4. **Закройте и откройте проект ещё раз.** После второго запуска предупреждений
   быть не должно.
5. Закоммитьте появившиеся файлы:

   ```bash
   git add -A
   git commit -m "chore: commit Godot import metadata"
   ```

Ожидаемо появится около 156 файлов `.import` и до 285 файлов `.uid`
(по одному на скрипт).

> Если предупреждения об UID остались после второго открытия: закройте
> редактор, удалите каталог `.godot/` целиком и откройте проект снова.

## Шаг 2. Проверка в редакторе (до F5)

Панель **Output** после открытия проекта:

- [ ] Нет красных строк `SCRIPT ERROR` / `Parse Error`
- [ ] Нет `Failed to load script`
- [ ] Нет `Node not found`
- [ ] Нет `cannot be created` (ресурс в роли ноды)

Полезно прогнать гейты в движке — они проверяют то, чего статика не видит:

```bash
godot --headless --script res://tools/scene_smoke.gd          # 17 сцен грузятся
godot --headless --path . res://scenes/tools/compile_gate_scene.tscn
godot --headless --path . res://scenes/tools/signal_arity_check_scene.tscn
godot --headless --path . res://scenes/tools/i18n_check_scene.tscn
godot --headless --path . res://scenes/tools/asset_check_scene.tscn
```

Все должны завершиться с кодом 0.

## Шаг 4. Визуальная проверка (после F5)

### 4.1. Запуск и меню

- [ ] Заставка сменяется экраном загрузки, затем главным меню
- [ ] Кнопки меню подписаны (не пустые прямоугольники)
- [ ] «Играть» открывает уровень и **игра остаётся в уровне**
      *Раньше через 3 секунды выбрасывало обратно в меню — исправлено,
      но это главное, что стоит проверить первым.*

### 4.2. HUD — не перекрываются ли элементы

Слева сверху пять полос идут строками с шагом 34 px:
здоровье (y≈30), выносливость (64), батарея (98), **шум** (132),
**заметность** (166).

- [ ] Пять полос идут одна под другой, без наложений
- [ ] Подписи «ШУМ» и «ЗАМЕТ.» не наезжают на полосы выносливости и батареи
- [ ] Цифры справа от полос читаемы и не обрезаны
- [ ] Внизу по центру шесть слотов, у каждого счётчик
- [ ] Кнопка паузы в правом верхнем углу не перекрыта радаром

> Расчёт раскладки делался арифметически, на экране я его не видел.
> Если полосы всё же наезжают — правится `BAR_ROW_PITCH` в
> `scripts/ui/hud_3d.gd`.

### 4.3. Свет и атмосфера

- [ ] Фонарь даёт конус света, а не точку и не засвет всего экрана
- [ ] Фонарь поворачивается вместе с камерой
- [ ] Уличные фонари горят только в запитанных районах
- [ ] Туман и ночное освещение на месте, сцена не чёрная и не белая
- [ ] Частицы пепла падают, а не висят

### 4.4. Укрытия — главное, что я не мог проверить

В каждом районе спавнится **5 укрытий** (шкаф, бак, машина, ящик) по кругу
радиусом 8–24 м от центра. Расстановка процедурная, коллизий с домами она
не учитывает.

- [ ] Укрытия стоят на земле, а не висят в воздухе и не утоплены в грунт
- [ ] Ни одно не оказалось внутри стены дома
- [ ] К каждому можно подойти
- [ ] При подходе появляется подсказка «Спрятаться»

> Это самое вероятное место для визуальных дефектов. Правится числом
> и радиусом в `HIDING_SPOTS_PER_DISTRICT` / `HIDING_RADIUS_MIN/MAX`
> в `scripts/world/district_scene_factory.gd`.

### 4.5. Переходы между экранами

- [ ] Escape ставит паузу, второй Escape снимает
- [ ] При открытом Кодексе Escape закрывает **Кодекс**, а не открывает паузу поверх
- [ ] Пауза → «В меню» действительно уводит в меню **и не вешает игру**
      *Здесь был фатальный баг: экран уходил в чёрный и застревал навсегда.*
- [ ] Пауза → «Заново» перезапускает уровень
- [ ] Карта (K), журнал (J), энциклопедия (L) открываются и закрываются
- [ ] Пока открыт блокирующий экран, HUD скрыт и не рисуется поверх меню
- [ ] Переход между районами без зависаний и рывков

## Шаг 5. Проверка геймплея

### 5.1. Предметы

- [ ] Предметы лежат на земле, покачиваются, не проваливаются под неё
- [ ] При касании предмет исчезает и **счётчик в слоте HUD растёт**
- [ ] Перегруженный рюкзак: предмет остаётся лежать, появляется уведомление
- [ ] **Аптечка (слот 3) восстанавливает 35 HP** — полоса здоровья растёт
- [ ] **Батарейка (слот 2) добавляет 40 заряда** — полоса батареи растёт

> Аптечки и батарейки не работали вовсе: сигнал слушал контроллер из 2D-версии,
> которого нет в игровой сцене. Это стоит проверить обязательно.

### 5.2. Стелс

- [ ] Полоса шума растёт при беге и падает при ходьбе крадучись
- [ ] Монстр реагирует на шум и идёт проверять
- [ ] **Внутри укрытия монстр перестаёт видеть игрока и теряет цель**
- [ ] Выход из укрытия возвращает обычную видимость

### 5.3. Бой и смерть

- [ ] Враги появляются в районе, преследуют и атакуют
- [ ] Урон снижает здоровье, экран мигает виньеткой
- [ ] При нуле здоровья появляется **экран смерти**
- [ ] «Заново» на экране смерти перезапускает уровень с полным здоровьем
- [ ] «В меню» возвращает в главное меню

### 5.4. Мир

- [ ] Дверь открывается ключом `key` и не открывается без него
- [ ] Ключ с земли попадает в рюкзак (а не исчезает бесследно)
- [ ] Щиток района чинится деталями, район светлеет
- [ ] Событие блэкаута гасит уличные фонари примерно на 15 секунд

### 5.5. Звук

- [ ] Играет музыка в меню и в игре, при появлении врага настроение меняется
- [ ] Слышны шаги, звук подбора, включение фонаря
- [ ] Ползунки громкости в настройках работают

## Шаг 6. Сохранения

- [ ] «Продолжить» в меню появляется только при наличии сохранения
- [ ] Загрузка восстанавливает позицию, рюкзак и прогресс районов
- [ ] Ошибки записи сохранения видны в консоли
      *(диагностика была закомментирована — прогресс терялся молча)*

Отдельно стоит проверить три места, которые чинились последними:

- [ ] **Новая игра начинается с нуля.** Пройдите пару уровней, наберите
      опыт и навыки, затем «Новая игра» — уровень, опыт, дерево навыков
      и статистика должны обнулиться.
      *Раньше они переносились из прошлого забега.*
- [ ] **Загрузка слота возвращает в нужный район.** Сохранитесь в слот
      не в пригородах, загрузите — район должен совпасть.
      *Раньше слот не хранил район, и загрузка всегда бросала в пригороды.*
- [ ] **Автосейв на входе в район пишет новый район, а не прошлый.**
      Перейдите в соседний район, выйдите в меню, нажмите «Продолжить» —
      игрок должен оказаться в новом районе.
- [ ] **Тряска камеры при получении урона.** *Не работала вовсе: камера
      не передавалась в ScreenShake нигде, кроме сетевой игры.*

## Что делать с найденными дефектами

Если что-то из списка не сходится, заведите issue и приложите:

1. **Скриншот** — особенно для HUD и укрытий.
2. **Полный текст из Output**, а не пересказ: строка `res://...gd:НОМЕР`
   указывает точное место.
3. **Шаги воспроизведения** — где стояли, что нажали.
4. Вывод `./tools/check.sh --static`, если ошибка похожа на структурную.

### Наиболее вероятные визуальные дефекты

Честно: вот где я ошибусь скорее всего, потому что считал, а не смотрел.

| Дефект | Куда смотреть |
|---|---|
| Полосы HUD наезжают | `BAR_ROW_PITCH`, `_layout_extra_rows()` в `scripts/ui/hud_3d.gd` |
| Укрытия в стене или в воздухе | `_spawn_hiding_spots()` в `scripts/world/district_scene_factory.gd` |
| Лут висит или тонет | `DROP_Y`, `_scatter()` в `scripts/world/district_loot.gd` |
| Конус фонаря не тот | `scenes/player/player_3d.tscn`, узел `Flashlight` |
| Тёмный или пересвеченный кадр | `scripts/world_env_setup.gd`, `scripts/visual/night_env.gd` |
| Враги стоят на месте | навигация: `_setup_nav_region()` в `scripts/main_3d.gd` |
