# Privacy policy for Last Streetlight

Last updated 2026-11-19.

Last Streetlight is an offline single-player game. We collect and share no personal data. The game has no accounts, ads, advertising SDKs, analytics or crash-reporting service.

### Optional connection bonus

Android asks the operating system whether the active connection uses Wi-Fi. Wi-Fi without internet can qualify. On desktop, the game checks local network interfaces for a usable address. The web version reads the browser’s online status. These checks send zero network requests. The game transmits no IP address, Wi-Fi network name (SSID), device ID or gameplay data. Android uses ACCESS_NETWORK_STATE for the check and VIBRATE for touch feedback. The Android release does not request INTERNET.

### Local storage and deletion

Progress, settings and the record of claimed bonuses stay on your device. Export Save creates a local copy and Import Save reads it back. Share on the victory screen copies a summary to your clipboard. You choose whether to paste it anywhere. To delete local data, clear the app’s storage in Android settings, remove its local game data folder on desktop, or clear the site’s stored data in your browser. Delete any exported save copies separately.

Questions about this policy can be sent to **maxzimkasky@gmail.com**.

# Политика конфиденциальности игры «Последний фонарь»

Дата обновления — 19 ноября 2026 года.

«Последний фонарь» — одиночная офлайн-игра. Мы не собираем персональные данные и ни с кем ими не делимся. В игре нет аккаунтов, рекламы, рекламных SDK, аналитики и сервисов отправки отчётов о сбоях.

### Необязательный бонус за подключение

На Android игра запрашивает у операционной системы тип активного подключения. Для бонуса подходит Wi-Fi без доступа в интернет. На компьютере игра проверяет, есть ли у локального сетевого интерфейса подходящий адрес. В веб-версии она читает у браузера статус подключения. При проверке игра не отправляет ни одного сетевого запроса. IP-адрес, имя сети Wi-Fi (SSID), идентификатор устройства и игровые данные никуда не передаются. На Android разрешение ACCESS_NETWORK_STATE нужно для проверки подключения, а VIBRATE — для тактильного отклика. Разрешение INTERNET игра не запрашивает.

### Хранение и удаление данных

Прогресс, настройки и сведения о полученных бонусах остаются на устройстве. Экспорт сохранения создаёт локальную копию, а импорт читает её. Команда «Поделиться» на экране победы копирует итоги в буфер обмена. Вы сами решаете, куда их вставить. Чтобы удалить данные, очистите хранилище игры в настройках Android, удалите папку с локальными данными игры на компьютере или очистите данные сайта в браузере. Экспортированные копии сохранений удаляются отдельно.
