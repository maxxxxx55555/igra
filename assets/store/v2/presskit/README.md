### A/B test strategy note
Run **A vs C first**: hero-light (aspirational/safe promise) vs monster-face (threat/horror signal) are the two strongest semantic poles for a survival title — this split produces the cleanest CTR signal on genre self-selection. Winner faces **D** (POV agency framing) in round two; keep **B** as reserve for map-feature campaigns or strategy-audience placements. All four share palette + night mood, so post-test brand recognition carries across variants. Metrics: 7-day CTR window, min ~10k impressions per arm before reading results.
